# Third-party notice entries — agent m4_m6 (M4 membership inference, M6 model extraction)

No third-party source code was copied, ported or vendored into:

* `src/malvalid/modules/membership.py`
* `src/malvalid/modules/extraction.py`
* `tests/unit/test_membership.py`
* `tests/unit/test_extraction.py`

All of it is original code written for MalValid under Apache-2.0.

The following already-declared core dependencies are **imported** at runtime (not copied):

| name | license | URL | used in |
|---|---|---|---|
| Adversarial Robustness Toolbox (ART) 1.20 | MIT | https://github.com/Trusted-AI/adversarial-robustness-toolbox | `membership.py` (`MembershipInferenceBlackBox`, `BlackBoxClassifier`); `extraction.py` (`KnockoffNets`, `BlackBoxClassifier`, `ClassifierMixin`/`BaseEstimator` for a thieved-classifier shim that subclasses ART base classes, with no ART code copied) |

Machine Learning: Analyzing the Connection to Overfitting", IEEE CSF 2018 (the loss-threshold
membership attack).
