# Third-party notice entries — agent m5_m7 (M5 backdoor screening, M7 explanation)

No third-party source code was copied, ported or vendored into:

* `src/malvalid/modules/backdoor.py`
* `src/malvalid/modules/explanation.py`
* `tests/unit/test_backdoor.py`
* `tests/unit/test_explanation.py`

All of it is original code written for MalValid under Apache-2.0. The static tree-structure scan in
`backdoor.py` is an original heuristic (no published implementation was consulted or ported).

The following already-declared core dependencies are **imported** at runtime (not copied):
